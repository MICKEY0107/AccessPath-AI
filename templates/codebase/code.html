How the copy is kept safe

  • Shallow, read-only clone of one branch; the history is deleted afterwards.
  • Nothing in the repository is ever run: no installs, no scripts, no hooks.
  • Symlinks are not followed; .env, keys and build folders are never read.
  • Secrets are removed before code is shown or sent to an AI, and only providers marked “OK for private code” may read it.
