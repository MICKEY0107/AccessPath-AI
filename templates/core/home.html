Current implementation: keyboard-only motor accessibility

Evaluate whether a keyboard user can complete a real journey.

AccessPath AI will use bounded AI planning, deterministic keyboard policy checks, and browser evidence to evaluate a declared task.

View evaluation runs

How the evaluation works

  1. A configured journey defines an approved target, goal, keyboard profile, and completion policy.
  2. A separate worker opens a browser and observes the target state.
  3. The planner proposes one keyboard action; deterministic policy either rejects or authorizes it.
  4. The system records focus, state changes, and evidence before reporting a verified outcome or uncertainty.

Current safety boundary

Only approved, non-destructive fixture journeys are enabled during the initial build. The system does not log in, submit public forms, send messages, make payments, or claim complete WCAG conformance.
