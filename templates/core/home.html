Can a keyboard user finish the journey?

Current implementation: keyboard-only motor accessibility. AccessPath AI uses bounded AI planning, deterministic keyboard policy checks, and browser evidence to evaluate a declared task.

Get started

Run a journey Start a reference or website journey. Add a real website Evaluate a live public site, read-only. Review evidence Steps, focus path, and screenshots.

How the evaluation works

  1. A configured journey defines an approved target, goal, keyboard profile, and completion policy.
  2. A separate worker opens a browser and observes the target state.
  3. The planner proposes one keyboard action; deterministic policy either rejects or authorizes it.
  4. The system records focus, state changes, and evidence before reporting a verified outcome or uncertainty.

Current safety boundary

Evaluations never log in, submit forms, send messages, or make payments. Real-website runs are read-only, and results do not claim complete WCAG conformance.
